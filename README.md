# Electronic-Voting-Machine-DLD
A 4-candidate electronic voting machine designed entirely with digital logic. It uses gates, D flip-flops, multiplexers, decoders and BCD-to-7-segment displays, with no microcontroller. It has admin and vote modes, an SR-latch vote lock, anti-repeat logic, per-candidate 3-bit flip-flop counters, and live 7-segment result displays.
